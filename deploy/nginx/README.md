# Nginx template

`eduassets-api.conf.example` is an operator template, not an active or verified production configuration. Replace the hostname and certificate paths only after DNS/TLS are configured. The repository includes `eduassets-cloudflare-realip.conf.example`, retrieved from Cloudflare's official IP-range sources on 2026-10-22. Re-check the official list immediately before installation and periodically thereafter; copy the reviewed ranges to `/etc/nginx/snippets/eduassets-cloudflare-realip.conf`. Validate the complete configuration with `nginx -t`, and restrict inbound origin traffic to those ranges at both the cloud network security layer and the host firewall. Trust `CF-Connecting-IP` only after Nginx verifies the peer against this list. The API port must remain loopback-only; the template returns 404 for the public `/auth/rfid` and `/ws/rfid` endpoints because a loopback address observed by Nginx is not proof that the original caller is local. Keep RFID functionality in a separately secured kiosk configuration. A direct, non-Cloudflare deployment needs a separately reviewed proxy trust policy.

Official sources: [Cloudflare IP Ranges](https://www.cloudflare.com/ips/) and [Cloudflare IP addresses documentation](https://developers.cloudflare.com/fundamentals/concepts/cloudflare-ip-addresses/).
