# Template Nginx

`eduassets-api.conf.example` é um template para operadores, não uma configuração de produção ativa ou verificada. Substitua o nome do host e os caminhos dos certificados somente após configurar DNS/TLS. O repositório inclui `eduassets-cloudflare-realip.conf.example`, consultado nas fontes oficiais da Cloudflare em 2026-10-22. Confira os ranges oficiais imediatamente antes da instalação e periodicamente; copie a lista revisada para `/etc/nginx/snippets/eduassets-cloudflare-realip.conf`. Valide a configuração completa com `nginx -t` e restrinja o tráfego de entrada para a origem a esses ranges tanto na segurança de rede da nuvem quanto no firewall do host. Só confie em `CF-Connecting-IP` depois que o Nginx validar o peer contra essa lista. A porta da API deve permanecer acessível somente por loopback; não encaminhe `/ws` nem a porta de provisioning RFID. Uma implantação direta, sem Cloudflare, requer uma política de confiança de proxy revisada separadamente.

Fontes oficiais: [ranges de IP da Cloudflare](https://www.cloudflare.com/ips/) e [documentação de endereços IP da Cloudflare](https://developers.cloudflare.com/fundamentals/concepts/cloudflare-ip-addresses/).
